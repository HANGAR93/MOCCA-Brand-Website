MOCCA — Brand Website

Personal project showcasing a cinematic brand website concept focused on visual design, UX/UI and immersive interactions.

Overview

MOCCA is a two-page website prototype designed around a narrative scrolling experience rather than traditional independent sections.

The project focuses on creating a strong visual identity through typography, photography, animations and smooth transitions.

Pages
index.html — Home, About, Services, Clients and CTA
contact.html — Contact page
Key Features
Cinematic scroll experience
Scroll-based animations and transitions
Interactive services accordion
Parallax effects
Animated typography
Progressive content reveals
Responsive design
Graceful fallback if animations are unavailable
Technologies
HTML
CSS
JavaScript
GSAP
ScrollTrigger

GSAP and ScrollTrigger are loaded via CDN. If GSAP is unavailable, the website keeps its content and functionality as a standard webpage.
